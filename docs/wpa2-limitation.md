# 只支持 WPA2：为什么，以及实际影响

面向非技术人员的说明。技术依据在文末。

---

## 一、先说会不会影响你

**取决于你家的路由器是哪种设置。** 三种情况：

### 情况 1：路由器设成 WPA2（最常见）

**完全没影响，放心用。**

很多路由器出厂默认就是 WPA2，或者可以手动设成 WPA2。这是目前最普遍的家庭配置。

### 情况 2：路由器设成 WPA2/WPA3 混合模式

**能连，但要看路由器还留没留 WPA2 这条路。**

现在不少新路由器默认开混合模式（同时支持老的 WPA2 和新的 WPA3）。这种情况下**通常能连上**，因为 WPA3 是"可选加入"的，路由器同时保留 WPA2。

具体表现：

- 如果路由器菜单里有"WPA2/WPA3 混合"或"兼容模式"这样的选项 → **能用**
- 如果这个选项被关掉了，只剩 WPA3 → **连不上**

所以**先去看一眼路由器的设置界面**，确认混合模式没被关掉。

### 情况 3：路由器只支持 WPA3（WPA3 专用）

**连不上，没有办法。**

现在还不多，但新一些的路由器开始这样了。这是最需要担心的情况。

### 另外两种要注意的

**公司 / 学校 / 酒店的网络：连不上。**

这些地方用的是"企业级认证"（802.1X），需要账号密码配合证书，不是家用那种输个密码就行。这版不支持。

**很老的路由器（TKIP）：连不上。**

TKIP 是十几年前的技术，现在基本淘汰了。如果你用的是那种很老的路由器，需要在菜单里把加密方式改成 WPA2 或更新。

---

## 二、为什么只支持 WPA2

### 先说什么是 WPA2 和 WPA3

这两个是 Wi-Fi 的加密方式，可以理解成"门锁的等级"。

- **WPA2（2004 年）**：当年很先进，现在算中等
- **WPA3（2018 年）**：现在的主流，更难被破解

这几年新出的路由器和新手机，默认都在用 WPA3 了。

### 为什么只做了 WPA2

三个原因，从大到小：

#### 原因一：WPA3 换的不是一个零件，是整套流程

这是最关键的一点。

WPA2 的时候，你输密码，连上，完事。

WPA3 不是这样。WPA3 用了一种叫 **SAE** 的握手方式，意思是"你先别急着给我密码，我们先来回说几句话，确认一下你是不是真的知道密码，但**不把密码传过去"**。

这套"来回说话"（学名叫**四次握手**）跟 WPA2 的**两次握手**完全是两套逻辑。代码里要新增的东西包括：

- 新的握手状态机
- 大整数运算（密码学里的素数群运算，对性能要求不低）
- 新的报文格式解析
- 新的关联（连 AP）时的协商流程

**这不是加个开关，是新增一套子系统。**

#### 原因二：Apple 本身也没在 Sequoia 上完整支持 WPA3

这一点挺反直觉，但很重要。

你可能以为 macOS 15 支持 WPA3——**在苹果自己支持的网卡上确实支持**。但那个 WPA3 支持长在苹果自己的 Wi-Fi 驱动里，而那个驱动是闭源的，第三方拿不到源码、也没有文档。

所以这个 fork 想支持 WPA3，**没法参考苹果怎么做的，只能自己从头写**。

#### 原因三：作者选择先不做

作者的目标是"在极窄范围内先跑起来"。WPA3 是个大工程，加进来会推迟整个项目。而且作者手上没有 WPA3 路由器做验证——**写了代码也没法测**，不如先不发。

作者在说明里写得很诚实：源码里其实有 WPA3 相关的试验代码，但**没有作为可用功能启用**。理由就是没法验证。

### 顺带一个信息：WPA3 不是可有可无

WPA3 相比 WPA2 有一个实质改进：**即使你把 Wi-Fi 密码告诉别人（或者别人用"查看密码"功能看到了），对方也不能直接连上**，因为它需要设备本身就能证明自己知道密码。

所以如果你比较在意这个（比如访客网络、或者密码容易泄露的场景），少一个功能是有点可惜的。但这不是"网络不能用"级别的问题，只是安全性略低一些。

---

## 三、怎么判断你会不会受影响

### 第一步：看看你家的路由器用的是哪种

登录路由器管理页面（通常地址是 `192.168.1.1` 或 `192.168.0.1`，说明书里有），找到"无线设置 / Wi-Fi 设置 / 安全模式"。

| 你看到的 | 结论 |
|---|---|
| WPA2-PSK / WPA2-PSK/WPA3-PSK | ✅ 能用 |
| WPA2/WPA3 混合（兼容模式） | ✅ 能用 |
| 只有 WPA3，WPA2 相关选项是灰的或没有 | ❌ 连不上 |
| WPA2-Enterprise / WPA3-Enterprise | ❌ 企业认证，不支持 |

**关键**：看到"WPA3"不代表不能用。只要 WPA2 那条路还在，就能用。

### 第二步：判断家里有没有人需要企业认证

- 只有你在家用的普通 Wi-Fi → 不用管
- 公司发的 Wi-Fi / 学校 Wi-Fi / 酒店 Wi-Fi → 这些基本是 802.1X，用不了

### 第三步：确认密码加密方式

看路由器里有没有"TKIP"这个选项。有的老路由器默认是 TKIP，需要改成 **AES 或 CCMP**。

---

## 四、如果真的连不上怎么办

假设你路由器是 WPA3 专用。几个选择：

1. **改路由器设置** —— 大多数路由器可以降级成 WPA2 或混合模式。
   ⚠️ 安全性会下降。改成 WPA2 后，密码被看到就能直接连上。

2. **换路由器** —— 长期方案，但成本高。

3. **先看看情况 2** —— 很多你以为的"WPA3 路由器"，其实默认是混合模式，只是菜单里藏得深。值得先翻一翻。

4. **换方案** —— 如果你家路由器只能 WPA3，说明你家的设备比较新，**也许没必要折腾 macOS 15**，留在 macOS 14 用原生 Wi-Fi 反而省心。

---

## 五、一句话总结

**只要你的路由器还留着 WPA2，就完全没影响。** 现在绝大多数家用路由器都还留着。

真正需要担心的只有两种情况：**路由器只剩 WPA3**，或者你要连**公司/学校/酒店的企业网络**。

动手前先去路由器管理页面看一眼"安全模式"，就一秒钟的事。

## 附：技术依据

### WPA3/SAE 在代码中不存在

对 fork 源码全文检索 `SAE`（WPA3 的握手协议）**零命中**。不是配置关掉了，是根本没实现。

### 支持的加密方式只有 4 种

`itl80211/openbsd/net80211/ieee80211_crypto.h:57-63`：

```c
enum ieee80211_akm {
    IEEE80211_AKM_NONE        = 0x00000000,
    IEEE80211_AKM_8021X       = 0x00000001,
    IEEE80211_AKM_PSK         = 0x00000002,   // WPA2 密码
    IEEE80211_AKM_SHA256_8021X= 0x00000004,
    IEEE80211_AKM_SHA256_PSK  = 0x00000008
};
```

WPA3 需要的 `SAE` 类型不在枚举里。

### WPA3 的握手类型被直接忽略

`itl80211/openbsd/net80211/ieee80211_input.c:1479-1504` 只认 4 种，认不出的返回 `IEEE80211_AKM_NONE` 并附注释 `/* ignore unknown AKMs */`：

```c
case 1: return IEEE80211_AKM_8021X;   // WPA/WPA2 企业认证
case 2: return IEEE80211_AKM_PSK;     // WPA/WPA2 密码
case 5: return IEEE80211_AKM_SHA256_8021X;
case 6: return IEEE80211_AKM_SHA256_PSK;
```

RSN 标准里 WPA3 对应的类型码（SAE 是 3、FT 系列是 7/8）落不到任何 case，直接被忽略。

### PMF（802.11w）有条件支持

`itl80211/openbsd/net80211/ieee80211_node.c:1659` 有一处 `ic_native_pmf &&` 参与判断。这是"受保护的管理帧"，属于 WPA3 的配套机制。fork 里是**有条件启用**，但对应能力未作为可用功能开放——所以"强制 PMF 的网络"被列为不支持。

### 加密套件（cipher）

`ieee80211_crypto.h` 同文件只定义到 `CCMP` / `TKIP` / `BIP` / `WEP`。WPA2-PSK/CCMP 是其中唯一被完整支持的组合，与 RELEASE_NOTES 声明的"WPA2-Personal/CCMP"一致。

### 混合网络的实际行为

RSN 解析会累计 `ni_supported_rsnakms`（`ieee80211_input.c:2111`、`:2580`）。混合模式的 AP 会同时广播 WPA2 和 WPA3 的 AKM 列表，驱动从中挑出认识的 WPA2 那条，因此**混合模式可以连接**。只有当 AP 仅广播 WPA3 能力时才会失败。
